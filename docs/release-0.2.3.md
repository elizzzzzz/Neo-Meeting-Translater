# 0.2.3：完整发言记录与历史翻阅

此前识别结果使用四秒滚动音频反复覆盖同一字幕编号，持续发言时前面的内容会消失。现在每个识别片段保留独立编号，已完成片段不会被新音频替换；相邻、同一发言人的片段合成一段，保持左原文、右译文。停顿本身不会让同一发言人另起一段；换人后建立新段，再次回到之前的发言人时也会另起一段。历史记录一直保留在当前会话内，关闭 App 前可导出。

音频上下文上限增至八秒。带词时间信息的模型在完整词的边界提交，保留少量重叠音频用于衔接，只修订当前未完成部分。识别提示词只使用已完成片段，避免当前草稿反复反馈导致漏字和重复错误。纠正原文后，旧译文会暂时保留，待新译文返回再替换。停止时先处理已采集的尾部音频；重新开始录音使用独立会话编号，避免覆盖之前的记录。

字幕区独立滚动：最新内容默认在底部；上滚翻阅时暂停跟随，收到新字幕也保持阅读位置。点击“回到最新”恢复跟随。主窗口与半透明浮窗都保留双栏。

增加小型本地声纹组件（sherpa-onnx、CAMPPlus），无需 PyTorch。仅在声纹权重成功加载后提供“自动分人（测试）”；匿名编号在一次录音内保持一致，连续两次候选判断后才切换。模型未连接时可“手动换人”，该操作保留已有音频后再开始新段，并切换为手动模式。自动判断存在约数秒的确认延迟，短插话、相似音色、多人重叠及噪声可能判断错误；不是腾讯会议/Teams 参会者身份识别，不显示真实姓名。

本机声纹模型保存在 `~/Library/Application Support/LocalMeetingInterpreter/models/speaker/campplus-zh-cn.onnx`，也可通过 `MEETING_INTERPRETER_SPEAKER_EMBEDDING_MODEL` 指定另一条本地路径。运行时不会自动下载。新的免安装包包含声纹运行组件，语音识别、翻译和声纹权重仍独立于 App。开发环境构建需安装 `.[apple,installer,speaker]`。

声纹模型来自 sherpa-onnx 官方发布的 `3dspeaker_speech_campplus_sv_zh-cn_16k-common.onnx`，文件大小 28,281,138 字节，SHA256：`f682b514c05d947ee3fa91cd6ec6c5c7543479a128373fa29b1faedccd21fd11`。

“本地设置”增加语音转文字引擎选择，支持 Whisper 与 SenseVoice（测试），后者需本地 ONNX 权重和 Silero 语音活动检测文件，运行时不下载。独立检测过滤 SenseVoice 的静音/噪声错误字幕，也可辅助 Whisper 避免把实际讲话仅因无语音概率偏高整句拒绝。没有辅助检测文件时 Whisper 保留原有过滤。

中文与日语专项实测见 [中日识别评估](asr-evaluation-0.2.3.md)。当前合成样本中 SenseVoice 中文明显更快，日语仍优先保留 Whisper 作基线；两者均有错字和分段遗漏，未完成自然会议准确率验收。本次未自动更换用户的默认识别引擎。模型及测试录音不包含在免安装包和源代码仓库中。

验证：50 项 Python 测试、18 项前端测试通过；桌面多尺寸布局、双栏历史滚动、原生半透明浮窗检查通过。包内 SenseVoice、Silero、声纹和 Ollama 实际加载完成，并回放合成中文→日语、日语→中文，检查手动换人、停止收尾、静音无字幕及第二次启动沿用现有实例。ZIP 解压与 DMG 挂载均通过 arm64、依赖文件和签名验证。回放链路可用不代表译文语义和识别准确率完全验收；尚未完成真人麦克风和腾讯会议/Teams 实际会议测试。机器负载高时音频积压仍会触发实时优先策略，并在界面提示跳过的秒数。

最终包内也已实测 Whisper medium + Silero 的中文金额样本与日语→中文链路，确认原先错误拒绝的整句能显示。两种引擎在当前分段回放中均仍有错字和遗漏，日语“訳文”的同音识错会影响译文；详见评估记录。
