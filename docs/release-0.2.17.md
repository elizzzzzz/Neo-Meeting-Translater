# 0.2.17 — 保存设置后自动应用

模型、运行服务、本机服务地址和模型目录保存后自动应用，不再要求退出或重启 App。中文、日语、英语界面均显示“正在应用 / 加载进度 / 已生效”，加载失败会显示具体原因；保存成功和加载成功分别反馈。

录音期间可以编辑和保存设置。App 先收尾已接收音频并暂停收音，保留已有原文、译文和历史段落；所选模型就绪后自动恢复。等待期间可以点击“停止”取消自动恢复。切换期间的声音不会被录入，不能视为无间断会议录音。收尾超时或外部客户端被强制关闭时，导出记录会标记可能存在缺失。

服务端先等待旧会话和正在执行的原生任务结束，再释放旧模型、应用保存配置并准备新模型。不会通过取消 Python 等待来假定原生推理已经停止。连续保存会串行处理并采用最新选择，旧服务检测结果不会覆盖新模型状态；加载失败后可修改设置再保存重试。

Apple 语言资源仍须显式点击准备；不会因刷新列表或启动而下载。缺少资源时会显示原因。Whisper 模型缓存随旧模型释放，内置翻译器显式使用更新后的缓存目录。Ollama / llama.app 继续管理其服务和模型文件，本次没有升级或修改这些服务。

验证：

- 148 项 Python 测试通过，1 项跳过：覆盖同一服务进程内的模型和目录切换、服务地址和翻译模型更新、冷启动期间连续保存、识别任务未完成时的安全切换、失败恢复及缓存目录更新。
- 58 项前端测试通过：覆盖记录保留、收尾先于保存、新模型就绪后只恢复一次、停止取消恢复、旧连接完全关闭前禁止恢复和加载失败提示。
- Chromium 模拟音频测试通过实际按钮执行录音中保存和自动恢复；原文与译文仍保留。中、日、英界面在 1440×900、1280×720、1024×768 的布局无整页溢出或页面脚本错误。
- arm64 ZIP 解压与 DMG 挂载、可执行权限、App / Apple 组件签名检查通过；交付 App 版本和内嵌界面与当前源码一致，Apple 组件只读检测通过；检测时中文、日语资源已安装，英语资源尚未安装。
- 以上测试使用隔离配置和模拟识别、翻译，不下载模型、不录制真实麦克风、不改变用户的模型设置。本次没有进行真实 Apple 中文/日语识别或会议端到端延时实测。
