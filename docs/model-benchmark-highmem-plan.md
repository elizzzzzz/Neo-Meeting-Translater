# 高配环境模型测试计划

## 环境

- 设备：Apple M5 MacBook Air
- 统一内存：32 GiB
- 加速：Apple Metal
- 首阶段平台：Ollama 0.40.16，独立临时模型仓库
- 测试语料：沿用 2026-11-09 冻结的中日英六方向、144 题会议翻译集

## 队列

首阶段按顺序测试以下大于 8B 且不超过 70B 的 Ollama 模型标签。Ollama 标签的实际量化、下载大小和摘要在下载完成后写入状态文件；模型完成 144 题测试后立即删除，再进入下一项。

1. `qwen2.5:14b`
2. `qwen3:14b`
3. `qwen2.5:32b`
4. `qwen3:32b`
5. `deepseek-r1:32b`
6. `deepseek-r1:70b`
7. `llama3.3:70b`

如果某个标签不可获取、在 32 GiB 统一内存上无法启动或连续超时，会保留失败日志并继续队列；不把失败当作翻译质量结论。后续再为可行模型补测 llama.cpp GGUF 和 SGLang MLX 变体。

## 采集指标

- 下载阶段：当前层、已完成字节、总字节、下载速度、日志路径
- 推理阶段：144 题成功数、平均/中位延迟、平均解码 TPS、TTFT、进程树 RSS 峰值、系统可用内存和 swap
- 质量阶段：输出保存为 JSONL，统一标记 `scoring_pending`，待逐题盲评后才进入综合排名

下载与推理严格串行：推理期间不执行 `ollama pull`；每个模型结束后执行 `ollama rm` 并验证临时仓库清理。
