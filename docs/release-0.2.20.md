# NMT 0.2.20

简化设置完成和再次启动的流程。

- 设置页主按钮改为“保存并返回”。本地配置保存成功后，自动回到主界面，无需再点击关闭。
- 模型继续在后台准备；主界面显示加载进度及错误。保存失败时保持设置窗口和已输入内容，方便修正重试。
- 已保存过模型配置后，再次打开不重复弹出使用提示或设置引导；自动兼容旧版配置，不要求重新勾选“以后不再提醒”。
- 配置是否完成与磁盘、模型、服务当前是否可用分别判断，避免模型暂时不可用时反复进入初始设置。
- 使用指南和本地设置仍可从侧栏手动打开，亮暗外观、语言选择及原有字幕记录逻辑保留。

验证：73 项前端测试、170 项后端及 macOS 桥接测试通过，1 项跳过。界面检查使用明确标注的测试数据，覆盖保存后自动返回、再次加载跳过引导、手动查看使用指南，以及原有单屏布局、外观与录音设置应用流程；未重新测量真实识别准确率或推理延时。

交付验证：已构建 arm64 便携 ZIP 和 DMG，ZIP 解压、DMG 只读挂载和包内签名检查均通过。只读核对本机已有配置：已完成设置，启动引导关闭；未修改模型或用户配置。
