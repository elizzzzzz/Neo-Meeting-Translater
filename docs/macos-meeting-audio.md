# macOS 会议音频接入

腾讯会议和 Microsoft Teams 都可以通过 macOS 虚拟音频设备把远端声音送入本地字幕管线。推荐使用 [BlackHole](https://github.com/ExistentialAudio/BlackHole) 的 2ch 设备。

## 推荐连接方式

1. 安装 BlackHole 2ch。
2. 在腾讯会议或 Teams 的音频设置中，将“扬声器 / Speaker”选择为 `BlackHole 2ch`。
3. 启动本项目，浏览器允许麦克风权限。
4. 在输入设备下拉框中选择 `BlackHole 2ch`。
5. 点击“开启本地麦克风”，字幕页面会接收会议远端声音。

这条路径把会议远端声音作为本地音频输入处理，不需要上传会议录音，也不依赖腾讯会议或 Teams 的云端转写接口。

## 同时听到会议原声

如果希望自己仍然听到会议原声，请在 macOS“音频 MIDI 设置”中创建多输出设备，把 Mac 耳机和 BlackHole 2ch 同时加入；然后把腾讯会议或 Teams 的扬声器设置为该多输出设备。

如果只需要翻译字幕，直接选择 BlackHole 2ch 即可，系统不会把翻译文本重新送回会议。

## 麦克风与会议远端声音

第一版建议分两路测试：

- 本机发言：选择 Mac 内置麦克风或耳机麦克风；
- 远端发言：选择 BlackHole 2ch。

浏览器一次只采集一个输入设备。后续加入音频混音器后，可以把两路音频合并成一个会话，并通过 `source` 字段保留来源。

## 权限与排错

- 在“系统设置 → 隐私与安全性 → 麦克风”中允许浏览器访问麦克风。
- 如果设备没有出现在下拉框中，先关闭并重新打开浏览器，再确认 BlackHole 已在“音频 MIDI 设置”中出现。
- 如果出现回声，将会议客户端输出改为耳机，或只把 BlackHole 作为输入设备使用。
- 混合音频中多人同时讲话时，说话人区分会比独立音轨更困难；第一版应先验证轮流发言场景。
