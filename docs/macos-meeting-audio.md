# macOS 系统音频接入

NMT 可以使用 macOS ScreenCaptureKit 原生采集指定窗口的声音，把本地播放器、腾讯会议、Microsoft Teams 或浏览器视频的音频送入本地识别管线。音频只在本机处理，不调用会议软件的云端转写。

## 使用方法

1. 启动 NMT，在“音频输入”选择“系统音频 / 播放器声音（原生采集）”。
2. 点击开始。首次使用时，在 macOS 的“屏幕录制”权限提示中允许 NMT。
3. NMT 会列出当前可采集的窗口。选择正在播放视频或会议的窗口。
4. 等待状态显示系统音频已开启，再查看字幕。
5. 停止会议后点击停止，NMT 会结束窗口采集。

系统音频采集不需要安装 BlackHole 2ch 或 Loopback。旧版 macOS 或无法使用 ScreenCaptureKit 时，仍可以选择兼容的虚拟音频设备作为回退输入。

## 权限与限制

- 系统音频捕获需要 macOS 13 或更高版本，并需要在“系统设置 → 隐私与安全性 → 屏幕录制”允许 NMT。
- 只有用户选择的窗口声音会进入识别；NMT 不保存屏幕画面。
- 某些受版权保护或受系统保护的播放器可能拒绝音频捕获。遇到这种情况，使用播放器的普通音频输出或兼容虚拟音频设备。
- NMT 一次采集一个窗口。需要同时识别麦克风和远端声音时，请选择已混合的音频输入，或先分别测试两路音频。
- 屏幕录制权限只用于 ScreenCaptureKit 音频流，识别、翻译和字幕仍在本机运行。
