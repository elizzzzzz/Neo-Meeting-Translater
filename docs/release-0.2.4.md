# 0.2.4 · 保留完整音频与逐步显示译文

修复旧版“保持实时 · 已跳过若干秒积压”的漏音问题。旧版等待识别和整句翻译完成才确认收包，前端超过 4 秒的积压会淘汰旧音频；新版接收音频、识别、翻译分别推进，音频写入本机临时缓冲后立即确认。

- 识别积压时合并过时的临时刷新，完整历史窗口照常识别；停顿、手动换人和停止均保留尾句。
- 原文约每 600ms 请求刷新；长会议按采样总数计时，避免逐包舍入导致时钟漂移。
- Ollama 生成译文时逐步显示，修订原文保留当前译文，旧翻译不会回退较新的原文。
- 修复轻声会议发言被语音检测器误判为静音：只对检测器输入做有限增益，原音频与噪声防护保留。
- 开始收音前先准备所选识别语言，显示准备状态并允许取消；复用已预热的语音检测器，减少开场积压。
- 清理中文、日语分词产生的多余空格；识别积压和待翻译段数持续显示。
- 缓冲容量不足会明确暂停收音并报告记录可能不完整，不再用丢弃未识别音频维持“实时”。

保持 macOS 原生窗口、单实例、半透明可移动字幕浮窗、中日与中英双向翻译、本机处理和文字优先。用户已有模型目录和引擎设置不会因升级而改写。语音输出仍未加入。

提供 arm64 免安装 ZIP 和 DMG。解压 ZIP 后可直接打开 `.app`；建议保存到不受 iCloud 管理的目录。模型单独保存在用户指定目录。0.2.3 的本机副本保留用于回退。

本次自然录音评估、准确率与延迟目标的差距见 [长段实测报告](asr-evaluation-0.2.4.md)。`音频无缓冲丢弃`不表示模型没有漏字；约 1 秒原文、再约 1 秒译文尚不构成稳定保证。

开发验证：67 项 Python 测试（含本机真实模型的轻声/静音/噪声回归）、21 项前端测试；ZIP 解压、DMG 挂载、arm64 架构和严格签名验证通过。原生包实际模型加载、单实例及自然语音接口回放结果在实测报告中单独记录。测试不代替真实麦克风、腾讯会议或 Teams 回环实测。
