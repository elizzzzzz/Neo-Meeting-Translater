# NMT 0.2.18

LocalMeetingInterpreter 更名为 **NMT（Neo Meeting Translater）**。界面参考 LM Studio 的桌面工作区，采用深灰背景、淡紫色强调、紧凑图标侧栏和更清晰的双语发言区域。

- 新增 NMT 标识和应用图标；原生窗口标题、Finder 显示名和新构建产物使用 NMT。
- 重整设置、使用提示和半透明字幕模式的视觉样式；保留中日英界面切换、固定语言双栏、连续发言和历史滚动。
- 图标按钮提供本地化名称及悬停提示，浮窗退出按钮随状态更新。
- 保留原 bundle identifier、内部可执行文件名及 Application Support 目录，继续读取已有路径和偏好设置；旧版与新版共用单实例锁。
- 新产物：`NMT.app`、`NMT-portable.zip`、`NMT.dmg`。历史 0.2.17 发布文件保持原名。

验证：61 项前端测试、164 项后端及 macOS 桥接测试通过，1 项跳过。通过 1440×900、1280×720、1024×768 三种桌面尺寸及中文、日文、英文界面检查，并检查 390px 窄窗、设置和字幕浮窗。界面测试使用明确标注的样例字幕，没有打开麦克风、下载或加载真实模型；不代表重新测量了语音识别准确率或翻译延时。

原生交付验证：arm64 `NMT.app` 已启动并实际检查深色主窗口、字幕浮窗和返回主窗口。便携 ZIP 解压、DMG 只读挂载及包内签名检查均通过。当前机器保存的翻译模型 `kaanmotivasyon02/translategemma:4b` 返回 404；此设置保留，未自动替换或下载模型。
