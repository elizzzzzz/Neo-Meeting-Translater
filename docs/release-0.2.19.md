# NMT 0.2.19

新增亮色、暗色及跟随系统外观，保留 NMT 的淡紫色标识和以对话为主的单屏布局。

- 侧栏太阳 / 月亮按钮一键切换亮色和暗色，切换后使用手动选定的外观。
- “本地设置 → 外观”可选择亮色、暗色或跟随系统；默认跟随系统，响应 macOS 实时外观变化。
- 设置立即生效并自动保存，重新打开仍保留；与模型设置、使用提示、界面语言分别保存。
- 原生窗口标题栏、主界面、设置和半透明字幕浮窗同步配色；中文、日文、英文提示均已补齐。
- 切换外观保留字幕、历史滚动位置和音频会话，不触发模型重新加载。

验证：67 项前端测试、167 项后端及 macOS 桥接测试通过，1 项跳过。界面检查覆盖三种桌面尺寸、三种界面语言、亮暗切换、系统外观变化、设置持久化和浮窗；使用明确标注的样例字幕，不代表真实识别准确率或推理延时实测。

交付验证：arm64 便携 ZIP 解压、DMG 只读挂载和包内签名检查通过。实际打开 0.2.19 原生 App，确认亮暗切换同步标题栏，并可选择“跟随系统”。当前本机保存的翻译模型仍返回 404；未自动替换或下载模型。
