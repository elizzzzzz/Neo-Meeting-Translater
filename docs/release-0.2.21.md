# NMT 0.2.21

本版本修复 macOS 安装包的交付方式：

- 新增标准 `NMT.pkg` 双击安装器，默认将 NMT 安装到“应用程序”。
- DMG 增加标准“应用程序”快捷方式，打开 DMG 后拖放安装，不会把磁盘映像误当作安装器直接运行。
- 保留 `NMT-portable.zip` 免安装包，便于测试和临时使用。
- 构建脚本支持 Developer ID 应用签名、安装器签名和 Apple 公证；没有证书时仍生成可运行的 ad-hoc 测试包，并明确标识未公证状态。
- 发布验证增加 PKG 载荷检查、DMG `/Applications` 快捷方式检查，以及 ZIP/DMG/App 的 arm64 和签名检查。
- 中英日 README 首段突出语音识别和翻译支持全本地方案，补充“隐私与安全性 → 仍要打开”的首次使用步骤；DMG 内附三语首次打开说明。
- 自动分人使用独立声纹缓冲区，清除过期候选，在明确停顿后加快一致声纹的确认，并保护已提交字幕的时间边界。同一人继续发言保持原段落。

当前交付按需求暂不进行 Developer ID 签名或 Apple 公证，PKG 不签名，App 保留本地 ad-hoc 签名。首次被 macOS 阻止时，在“系统设置 → 隐私与安全性 → 安全性”允许 NMT。后续如需开发者签名和公证，构建脚本仍保留可选入口，当前使用不要求配置证书。

验证：177 项后端测试通过，1 项跳过；73 项前端测试通过。声纹专项测试使用确定性的声纹向量验证分段链路，不代表真人识别准确率已经验收，详情见 `docs/speaker-segmentation-review-2026-11-23.md`。

交付文件：

- `NMT-portable.zip`：免安装包。
- `NMT.dmg`：拖放到“应用程序”的磁盘映像。
- `NMT.pkg`：双击安装器。
